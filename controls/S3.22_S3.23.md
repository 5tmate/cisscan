# S3.22 / S3.23：必須有 trail 記錄所有 S3 物件級寫入(3.8)/ 讀取(3.9)事件(均 Medium)

- **AWS 判定**:「checks whether an AWS account has at least one multi-Region trail that logs all write(read) data events for S3 buckets…This control produces a PASSED finding if you configure a multi-Region trail that logs write-only(read-only) or all types of data events for **all** S3 buckets.」
- **我們的實作**:帳號級。存在 multi-Region、logging 中的 trail，其 `event_selector` 的 `read_write_type ∈ {All, WriteOnly}`(S3.22)/`{All, ReadOnly}`(S3.23)，且 `data_resource` 為 `AWS::S3::Object` 且 values 是**全 bucket 選擇器**(`arn:aws:s3`、`arn:aws:s3:::*` 或 `arn:aws:s3:::*/*`)→ pass。
- **理由**:原文要求 all S3 buckets，只選了單一 bucket 的 data event selector 不满足，所以只認全域 ARN 形式。
- **已知限制**:用 `advanced_event_selector` 設定 S3 data event 的 trail 尚未支援(僅支援傳統 `event_selector`)，此情況會誤報 FAIL，待補。
