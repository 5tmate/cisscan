# S3.5：bucket policy 必須強制 SSL(CIS 2.1.1，Medium)

- **AWS 判定**:「checks whether an S3 bucket has a policy that requires requests to use SSL…indicated by the condition key `aws:SecureTransport`」，並附建議政策(`Effect: Deny`、`Principal: *`、`Action: s3:*`、`Condition Bool aws:SecureTransport: false`)。
- **我們的實作**:bucket policy(取自 `aws_s3_bucket_policy` 資源，或 bucket 自身的 `policy` 屬性)存在一條 statement 同時滿足:`Effect == Deny`、Principal 涵蓋所有人(`"*"` 或 `{"AWS": "*"}` 或 AWS 清單含 `*`)、Action 含 `s3:*` 或 `*`、`Condition.Bool["aws:SecureTransport"] == "false"`。Statement/Action/Principal 的單值與陣列兩種 JSON 形態都處理。
- **差異**:與 Config rule 一樣，不評估含萬用字元/變數的條件(AWS 原文亦明言此限制，見 S3.2 註)。
