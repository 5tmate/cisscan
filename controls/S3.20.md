# S3.20：bucket 必須開 MFA delete(CIS 2.1.2，Low)

- **AWS 判定**:「The control fails if MFA delete is not enabled…The control doesn't produce findings for buckets that have a lifecycle configuration.」(MFA delete 與 lifecycle 互斥，AWS 明文豁免)
- **我們的實作**:有 `lifecycle_rule` 的 bucket 不判(連 applicable 都不列，對應「doesn't produce findings」)，其餘 bucket 需 versioning enabled 且 mfa_delete 開啟，支援兩種來源:bucket 的 `versioning` 屬性(布林)，或獨立的 `aws_s3_bucket_versioning` 資源(`status/mfa_delete == "Enabled"` 字串，v4+ provider 格式)。
