# S3.1：帳號級 Block Public Access 全開(CIS 2.1.4，Medium)`cis_s3.rego`

- **AWS 判定**:「The control fails if one or more of the block public access settings are set to false…or if any of the settings are not configured.」四個設定:`ignorePublicAcls`、`blockPublicPolicy`、`blockPublicAcls`、`restrictPublicBuckets`。
- **我們的實作**:合成型別 `aws_s3_account_public_access_block` 四旗標全 true → pass，缺任一旗標、任一 false、或整筆不存在 → deny。
