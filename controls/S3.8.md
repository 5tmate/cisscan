# S3.8：bucket 級 Block Public Access 全開(CIS 2.1.4，High)

- **AWS 判定**:「The control fails if any of the following settings are set to false: ignorePublicAcls / blockPublicPolicy / blockPublicAcls / restrictPublicBuckets.」
- **我們的實作**:每個 bucket 必須有對應的 `aws_s3_bucket_public_access_block` 且四旗標全 true，沒有 PAB 設定 = 未設定 = deny。
- **閘門**:terraformer 不匯出 PAB,gated on `collected_types`，否則 P1 下所有 bucket 都會因 collector 盲區被誤報。
